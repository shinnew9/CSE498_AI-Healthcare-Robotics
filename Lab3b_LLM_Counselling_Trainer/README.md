# Lab 3b — LLM Mental Health Counselling Training App

CSE 498 · AI Healthcare Robotics

The simulated-patient trainer generated a new persona for every session and never read a stored one
back, so a counsellor could not return to a patient they had already seen. This lab adds returning
patients with cross-session memory, and completes the patient-profile screen.
